## What it is

Draft Den is a desktop app for writing novels. Your chapters, characters, places, timeline and maps
live together in one folder you own, and everything works offline.

## Beta

Draft Den is in beta. Expect rough edges: some inconsistencies and bugs are bound to happen. Keep
backups of your work (the app can make them for you), and feel free to report anything odd.

## Supported systems

| System | Status |
| --- | --- |
| Windows 10 and 11 (64-bit) | Supported (installer) |
| Linux, 64-bit: Ubuntu 22.04+, Debian 12+, Fedora 36+ and similar | Supported (AppImage, .deb, .rpm) |
| macOS | Coming soon |

Any 64-bit computer with 4 GB of RAM and about 200 MB of free disk space runs it comfortably.
